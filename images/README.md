# תמונות נדרשות לאתר

יש להניח את כל התמונות בתיקייה זו. הקבצים נטענים מ-`index.html` בנתיבים יחסיים.

## חובה

| קובץ | מידות | פורמט | שימוש |
|------|-------|-------|-------|
| `logo.png` | 400×400 (לפחות) | PNG עם רקע שקוף | לוגו בהדר ובפוטר |
| `hero.jpg` | 1920×1080 | JPG (איכות 85%) | תמונה ראשית בעמוד הבית |
| `about.jpg` | 800×1000 | JPG | תמונה בקטע "עליי / על העסק" |
| `og-image.jpg` | **1200×630 (חובה)** | JPG | תצוגה מקדימה ברשתות חברתיות |

## אייקונים (PWA + favicons)

| קובץ | מידות | פורמט |
|------|-------|-------|
| `favicon-16x16.png` | 16×16 | PNG |
| `favicon-32x32.png` | 32×32 | PNG |
| `apple-touch-icon.png` | 180×180 | PNG |
| `icon-192.png` | 192×192 | PNG |
| `icon-512.png` | 512×512 | PNG |

> כל ה-favicons ניתנים לייצור אוטומטי דרך https://realfavicongenerator.net מתוך `logo.png`.

## אופציונלי (לפי תחום)

- **משפטי**: תעודות ותמונות ייצוגיות במשרד
- **רפואי**: ציוד, חדרי טיפול
- **מסעדנות**: מנות (לפחות 6 תמונות במידות 800×600)
- **נדל"ן**: תמונות נכסים (לפחות 1280×800)

## טיפים לאופטימיזציה

```bash
# הקטנת JPG עם איכות 85% (איכות חזותית מצוינת, גודל קובץ קטן)
mogrify -quality 85 *.jpg

# המרה ל-WebP (חוסך 25-35% במשקל לעומת JPG)
cwebp -q 85 hero.jpg -o hero.webp
```

יעד: **כל תמונה מתחת ל-300KB**, רצוי 100-150KB.
